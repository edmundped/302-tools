302 Data Tools

Browser-side extraction desk for analyst tables.

Upload PDFs, preview detected tables, export tidy and review CSVs, and handle common cleanup jobs without sending source files to a server.

Local first

PDF uploads and CSV utilities run in this browser session. Scraping external URLs requires your configured CORS proxy.

Feature A

PDF Table Extractor

Drop PDFs here or choose files

Multi-page files are scanned for text-position tables. Scanned pages are flagged for OCR review.

Extraction note: geometry clustering is a starting point for financial statements and similar tables. Keep only the tables you trust after previewing them.
